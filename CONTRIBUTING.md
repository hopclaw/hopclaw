# Contributing

Thank you for your interest in HopClaw.

This public repository is not a source-available contribution target yet. The
runtime source code is not published here, and we are not accepting code pull
requests against the private core through this repository.

Useful ways to help right now:

- file high-quality bug reports against the latest visible release
- review installation and onboarding clarity
- report missing or confusing public documentation
- share integration requirements and workflow feedback grounded in real usage

Before opening an issue, please:

1. reproduce the problem on the latest visible release when possible
2. run `hopclaw doctor`
3. generate `hopclaw bug-report` when possible
4. collect version, platform, relevant logs, config fragments, and reproduction
   steps

Please do not:

- open public issues for security problems
- submit code pull requests for the private runtime core
- send source mirrors, unofficial repackaging, or speculative repository
  reshaping pull requests

We may open broader contribution paths later. When that changes, this document
will be updated.

## 简体中文

感谢你关注 HopClaw。

当前这个公开仓库还不是一个对外开放源码协作的目标仓库。运行时核心源码暂未
公开，我们也暂不通过这个仓库接收针对私有核心的代码 PR。

现在最有价值的参与方式：

- 针对最新公开版本提交高质量 bug 报告
- 审阅安装和 onboarding 流程是否清晰
- 指出公开文档里缺失或不清楚的内容
- 基于真实使用场景提供集成需求和 workflow 反馈

提交 issue 前，建议先：

1. 尽量在当前可见的最新版本上复现
2. 运行 `hopclaw doctor`
3. 如可行，执行 `hopclaw bug-report`
4. 准备好版本号、平台、相关日志、配置片段和复现步骤

请不要：

- 在公开 issue 中提交安全问题
- 向这个仓库提交私有运行时核心的代码 PR
- 提交源码镜像、非官方再打包或大范围仓库结构改造 PR

如果后续开放更完整的协作路径，我们会更新这份文档。
